## 📚 Topics & Problems Covered

### 1. 🔰 Basics & Loops
- **Basics:** Simple calculator, sum of $N$ natural numbers, introductory programs.
- **Loops & Numbers:** Factorial, reverse number, palindrome check, count digits, sum of digits, powers ($x^n$), prime number checking.

### 2. 🔷 Pattern Printing
- **Standard Patterns:** Star square, rectangles, right triangles, inverted triangles, numbered patterns, alphabet grids.
- **Advanced Patterns:** Hollow triangles, vertical triangles, binary number triangles, mirrored pyramids.

### 3. ⚙️ Functions & Number Theory
- Prime number generation ($1$ to $N$, optimized $\mathcal{O}(\sqrt{N})$ checks).
- Finding Factors and Count of Factors.
- Greatest Common Divisor / Highest Common Factor (HCF / GCD).
- Combinatorics: $n\text{C}r$ calculations.
- Trailing / Total zeros counter in numbers.

### 4. 📊 Arrays & Advanced Array Techniques
- **Fundamentals:** Array traversal, reverse array, swap alternate elements, find minimum/maximum element, array intersection.
- **Advanced Problems:**
  - Finding unique elements using XOR ($\mathcal{O}(N)$ time, $\mathcal{O}(1)$ space).
  - Finding duplicate elements (sorting & frequency counting).
  - Pair Sum and Triplet Sum problems.
  - Sort 0s and 1s (Two-pointer technique).
  - Sort 0s, 1s, and 2s (Dutch National Flag Algorithm).

### 5. 🔍 Searching & Binary Search Algorithms
- **Core Search:** Linear Search, iterative Binary Search.
- **Classic Binary Search Applications:**
  - First and Last Occurrence of an element in a sorted array.
  - Total number of occurrences.
  - Peak Index in a Mountain Array.
  - Pivot element in a Rotated Sorted Array.
  - Search in a Rotated Sorted Array.
  - Integer & Real Square Root using Binary Search.
- **Advanced Binary Search (Search on Answer Space):**
  - **Book Allocation Problem**
  - **Painter's Partition Problem**

### 6. 💡 LeetCode Solutions
- **LC 9:** Palindrome Number
- **LC 1207:** Unique Number of Occurrences
- *(More LeetCode questions continually added)*

## 🛠️ How to Compile & Run

All programs are written in modern **C++ (C++17 / C++20)**.

### Using GCC / G++ (Command Line)
```bash
# Compile
g++ -fno-lto filename.cpp -o filename.exe

# Run (Windows)
.\filename.exe

# Run (Linux / macOS)
./filename.out
```

### In VS Code
- Press **`F5`** or click the top-right **Play (▶)** button to automatically compile and run the active file in the integrated terminal.
